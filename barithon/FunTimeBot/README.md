# 🤖 FunTime End Bot

Автоматический бот для фарма данжей в Эндер-мире на сервере FunTime.

## 📋 Описание

Бот выполняет полный цикл фарма:
1. Подготовка (зелья, еда)
2. Поиск портала в Энд
3. Фарм ваз и песка
4. Сдача ресурсов
5. Выход через портал
